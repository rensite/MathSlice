# Проверка релизного кандидата

Проверено на этой Linux-машине, в настоящем headless Chromium с CPU WebGL. Сайт опубликован: https://d1w4ppp247h57e.cloudfront.net

Текущее состояние интерфейса: «Тела вращения» и «Университет» временно скрыты по запросу пользователя. Разделы и их кнопки отсутствуют в DOM и на desktop, и на телефоне. Код 12 гладких моделей сохранён; три браузерных сценария проверяют его через явное тестовое включение каталога, а не через доступный пользователю переключатель.

Приведённые выше результаты относятся к локальным и публичным production-проверкам. Целевой Git remote — `rensite/MathSlice`, доступ к нему и запуск GitHub Actions текущей учётной записью пока не подтверждены. Собственный домен не подключён: используется HTTPS-домен CloudFront. Автоматизированный деплой выполняется командой `npm run deploy` из рабочей копии, а не Git push-триггером.
